# GameNest

GameNest is a mini game hub I built to practice React and TypeScript. It lets users play small games, track scores, and unlock achievements.

## Features

* Tic-Tac-Toe
* Memory Match
* Number Guessing
* Rock Paper Scissors
* Scoreboard and game history
* Achievements
* Search games
* Dark/light mode
* Responsive design

## Tech

* React
* TypeScript
* Vite
* React Router
* LocalStorage

Open the local URL in your browser and start playing.
